# Changelog

All notable changes to Coder Cat are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.1.2] - 2026-11-17

### Changed

- Replaced the static JPEG dance image with an animated GIF.
- Removed the obsolete JPEG asset from the extension package.

## [0.1.1] - 2026-11-17

### Added

- Added a purple neon Coder Cat icon for VS Code and Marketplace listings.
- Added complete installation instructions for VSIX packages and the VS Code CLI.
- Documented command usage, development workflow, requirements, and privacy behavior.

### Changed

- Expanded and reorganized the README for the Coder Cat brand.

## [0.1.0] - 2026-11-17

### Changed

- Renamed the extension from Disco Cat to Coder Cat.
- Renamed the command ID from `disco-cat.dance` to `coder-cat.dance`.
- Migrated internal identifiers and first-run state to the `coder-cat` namespace.
- Updated Webview titles, accessibility labels, tests, and documentation.

## [0.0.2] - 2026-11-17

### Changed

- Lowered the minimum supported VS Code version to 1.85.0.
- Added publisher and repository metadata.

## [0.0.1] - 2026-11-17

### Added

- Added the initial five-second dancing cat Webview.
- Added automatic first-run playback and the manual dance command.
- Added CSS dance and disco effects using the bundled cat photo.
