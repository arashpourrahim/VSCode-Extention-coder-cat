# Change Log

All notable changes to the "coder-cat" extension will be documented in this file.

- Rename the extension from Disco Cat to Coder Cat.

## [0.0.2]

- Lower the minimum supported VS Code version to 1.85.0.
- Add the extension publisher identifier.
