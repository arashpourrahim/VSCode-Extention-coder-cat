# Disco Cat

Disco Cat brings a dancing cat to the center of your VS Code editor for five seconds on the first run after installation.

## Features

- Automatically dances once, on the first activation after installation.
- Closes itself after five seconds.
- Uses the **Disco Cat: Dance!** command when you want an encore.
- Respects VS Code themes and reduced-motion preferences.

## Try it locally

1. Run `npm install`.
2. Press `F5` in VS Code to open an Extension Development Host.
3. If the first-run dance has already been recorded, open the Command Palette and run **Disco Cat: Dance!**.

## Build

Run `npm run compile` for a development build or `npm run package` for a production build.
